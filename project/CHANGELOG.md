# DD2603 — Project v1.1

## Overview

This release introduces demonstration replay functionality, new demonstration datasets (e.g., for stable imitation learning, or methods that require multimodal behavior), and improvements to the course project.

## New features

### Demonstration replays

Previously it was only possible to visualize the demonstrations in the web UI. Now, it's possible to also replay them in the simulator itself.

## New and updated datasets

Three independently versioned demonstration datasets are now available:

| Dataset | Version | Status |
|---|---|---|
| [insertion_container](https://github.com/GeoRob-Lab/dd2603-course/releases/tag/insertion_container-v1.0) | v1.0 | Updated |
| [insertion_container_with_obstacle](https://github.com/GeoRob-Lab/dd2603-course/releases/tag/insertion_container_with_obstacle-v1.0) | v1.0 | New |
| [insertion_fixed_container_pose](https://github.com/GeoRob-Lab/dd2603-course/releases/tag/insertion_fixed_container_pose-v1.0) | v1.0 | New |

The `insertion_container` dataset supersedes the original `insertion_vision.zip` dataset distributed with Project v1.0.

The original release remains available for reproducibility.
